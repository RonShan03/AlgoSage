AlgoMind is an AI-powered knowledge assistant for Data Structures & Algorithms.  
Unlike generic LLMs, AlgoMind provides:
- Retrieval-Augmented Generation (RAG) answers grounded in curated DSA knowledge.
- Step-by-step explanations with Python/Java/C++ code.
- Practice problems with tiered hints.
- Visualizations of algorithms in action.
